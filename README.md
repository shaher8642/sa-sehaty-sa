# منصة صحة (Seha) | الاستعلام عن الإجازات المرضية + لوحة تحكم 🩺

> **تنويه:** مشروع تعليمي يحاكي موقع `sehaty-sa.onrender.com` لأغراض
> التدريب والدراسة. المنشور على Render على الرابط:
> `https://sa-sehaty-sa.onrender.com/`

## 📋 وصف المشروع

تطبيق ويب يتيح للمستخدم الاستعلام عن حالة طلب الإجازة المرضية الخاص به
عبر إدخال **رمز الخدمة** و **رقم الهوية/الإقامة**. كما يحتوي على
**لوحة تحكم إدارية** تتيح إنشاء وتعديل وحذف سجلات الإجازات المرضية.

التقنيات المستخدمة:

- **Backend:** Flask (Python) + Gunicorn
- **Database:** SQLite (قاعدة بيانات ملفية)
- **Frontend:** HTML + CSS + JavaScript (Vanilla)
- **Auth:** جلسات (Sessions) مع مقارنة آمنة (constant-time)
- **Language:** عربي (RTL) مع خط Cairo

## 🚀 طريقة التشغيل المحلي

### المتطلبات
- Python 3.10 أو أحدث
- pip (مدير الحزم)

### الخطوات

1. **استنساخ المشروع:**
   ```bash
   git clone https://github.com/shaher8642/sa-sehaty-sa.git
   cd sa-sehaty-sa
   ```

2. **إنشاء بيئة افتراضية:**
   ```bash
   python -m venv venv
   source venv/bin/activate    # على Linux/Mac
   # أو
   venv\Scripts\activate       # على Windows
   ```

3. **تثبيت الحزم:**
   ```bash
   pip install -r requirements.txt
   ```

4. **تشغيل التطبيق:**
   ```bash
   python app.py
   ```

5. **افتح المتصفح على:**
   ```
   http://127.0.0.1:5000
   ```

## 📡 واجهة الـ API العامة

### `POST /api/public-lookup`

**المُدخلات** (form-urlencoded أو JSON):

| الحقل           | النوع   | الوصف                |
|-----------------|---------|----------------------|
| `service_number`| string  | رمز الخدمة (حتى 14 حرف) |
| `id_number`     | string  | رقم الهوية/الإقامة (10 أرقام) |

**المُخرجات** (JSON):

```json
{
  "success": true,
  "name": "عبدالرحمن القحطاني",
  "issue_date": "2026-09-25",
  "start_date": "2026-09-26",
  "end_date": "2026-09-28",
  "w_day": 3,
  "doctor": "د. أحمد الشهري",
  "doctor_title": "استشاري طب الأسرة"
}
```

### مثال باستخدام curl:
```bash
curl -X POST https://sa-sehaty-sa.onrender.com/api/public-lookup \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "service_number=GSL26063953142&id_number=1104279680"
```

## 🛠️ التخصيص

### تغيير بيانات الأدمن:
- عبر متغيرات البيئة: `ADMIN_USERNAME`, `ADMIN_PASSWORD`
- أو بتعديل القيم الافتراضية في `app.py`

### إضافة سجلات جديدة:
1. ادخل للوحة التحكم عبر `/admin/login`
2. اضغط "+ إضافة إجازة"
3. املأ النموذج واحفظ

### تعديل الألوان:
عدّل المتغيرات في بداية `static/inquiry/style.css`:
```css
:root {
    --primary-blue: #2c5aa0;   /* اللون الرئيسي */
    --dark-blue:    #1e3d6f;   /* اللون الداكن  */
    --light-blue:   #4a7bc8;   /* اللون الفاتح  */
}
```
